# Al Madina Super Store website

A responsive one-page business website built with plain HTML, CSS and JavaScript.

## Run in VS Code
1. Download and extract `al_madina_super_store_website.zip`.
2. Open the `al_madina_super_store` folder in VS Code.
3. Install the **Live Server** extension if needed.
4. Right-click `index.html` and choose **Open with Live Server**.

You can also open `index.html` directly in a browser; Live Server is recommended while editing.

## Files
- `index.html` — page content and layout
- `style.css` — colours, layout and responsive styling
- `script.js` — mobile menu and small scroll effects
